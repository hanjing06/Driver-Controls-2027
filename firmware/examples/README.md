# Warm-up Examples

Run these on a **Nucleo-F302R8**, in order. Each folder's README has the steps. Make each project yourself, because building the `.ioc` is the lesson.

| # | Folder | Teaches | Level |
|---|---|---|---|
| 1 | [`01-blinky/`](01-blinky/) | CubeMX, GPIO, UART, flashing | 🟢 |
| 2 | [`02-adc-pedal/`](02-adc-pedal/) | ADC + DMA, scaling (how the pedal works) | 🟢🟡 |
| 3 | [`03-can-loopback/`](03-can-loopback/) | bxCAN, filters, interrupts, float encoding | 🟡 |

Commit your work to `fw/onboarding-<yourname>` and open a PR for feedback. Onboarding PRs are for learning and don't get merged to `main`.
