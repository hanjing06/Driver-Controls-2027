## What it was

A carrier PCB for a **Nucleo-F302R8**. The Nucleo supplied 3.3 V, the clock, reset and the ST-LINK. Our board handled 12 V ↔ 3.3 V conditioning, lighting MOSFETs, LEDs, CAN and connectors. Its firmware lives separately in [uixt/VCU_2025](https://github.com/uixt/VCU_2025) (see [`2025-firmware.md`](2025-firmware.md)).

## Key parts used (from the schematic)

| Function | Part | Carry over to 2027? |
|---|---|---|
| MCU | NUCLEO-F302R8 (STM32F302R8) | → chip-down STM32F302R8T6 |
| CAN transceiver | MCP2551-I/P (5 V, through-hole) | Re-evaluate: 3.3 V SMD part |
| CAN ESD | NUP2105LT1G | Likely keep |
| Light drivers | FQP30N06L (TO-220 logic-level N-MOSFET) ×5 | Consider an SMD logic-level FET |
| Fuses | 0466.125NR ×14, 0001.2511 ×6, PPTC021LFBN-RC | Review ratings |
| Display | NHD-C0220BIZ (I²C, 3.3 V) | Keep or upgrade |
| Gear selector | 100DP6T1B1M1QEH rotary | Keep |
| Connectors | Molex MX150 (348302001) | Review |
| Indicators | LiteOn LTST 1206/0603 LEDs | Keep |
| Passives | 1206 resistors/caps | Consider 0805/0603 |

## Lessons / things to fix in 2027

*Fill this in as a team during Phase 1. Starters:*
- Schematic was one flat sheet → use **hierarchical sheets** so members can own blocks
- 5 V CAN transceiver on a 3.3 V system → pick one rail strategy
- Through-hole MCU board took a lot of space → chip-down should shrink the board
- Thermal shutoff redundancy was "planned". Decide the approach now
- Pin assignment lived only in the schematic → now in `docs/interface-control.md`
